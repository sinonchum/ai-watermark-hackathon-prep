# wm-hack

Suggested starter layout from the hackathon preparation notes. The Python files are placeholders only; they are not an implementation.

Official data belongs in `data/` and pre-downloaded weights in `weights/`. Both directories are gitignored.

Layout:

- `wm/`: watermark embedding, detection, attacks, metrics (placeholders)
- `met/`: model equality testing, sampling and MMD tests (placeholders, not implemented)
- `unlearn/`: machine unlearning baselines and membership inference evaluation (placeholders, not implemented)
- `tasks/`, `app/`: submission helpers and demo app (placeholders)
